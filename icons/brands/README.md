# Brand logos

Official logos of the built-in web shortcuts, from
[Simple Icons](https://simpleicons.org) v16.33.0, released under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Each logo remains a trademark of its owner; it is shown only to identify the
site a shortcut searches.

Files named `*-symbolic.svg` (brands whose color is black) are recolored by
GNOME to the current text color, so they stay visible in dark and light themes.
